# Clone-de-red-social---sala2
Este proyecto es una página web sencilla inspirada en los Reels de Instagram. Fue creada como parte de mi aprendizaje de HTML y CSS, practicando la estructura de una página, clases, selectores y estilos.

También utilicé Git y GitHub para gestionar los cambios y subir el proyecto a un repositorio. El objetivo fue aplicar de manera práctica los conocimientos básicos que estoy aprendiendo en desarrollo web.
